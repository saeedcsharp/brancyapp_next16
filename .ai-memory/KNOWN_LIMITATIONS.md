# Known Limitations

- This repo is frontend-only for most domain behavior; database internals and backend implementation details are not present.
- Generated/vendor folders (`node_modules/`, `.next/`) are present locally and documented as generated modules, but their full internal trees are intentionally summarized.
- Endpoint request/response schemas are inferred from frontend types and usage unless backend docs are added.
- Automated tests were not discovered.
