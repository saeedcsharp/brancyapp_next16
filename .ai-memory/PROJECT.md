# Project

Brancy is a social commerce and Instagram business management web application. It supports Instagram page management, messaging, comments, post/story publishing, advertising, market/bio-link pages, stores, orders, shipping, wallet/payment flows, AI tools, and localized public pages.

The repository is the frontend application. Persistent business data and most domain operations live in external Brancy backend APIs.
