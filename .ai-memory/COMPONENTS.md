# Components

The `components/` tree contains shared UI primitives and feature-specific components for accessibility pages, ads, customer ads, design tools, graphs, navigation, notifications, page tools, sign-in/sign-out, store, user panel, website landing pages, and upgrade flows.

Component modules are documented individually under `MODULES/components-*.md`.
