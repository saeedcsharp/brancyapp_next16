# Features

## Public And Marketing

Landing page, pricing, accessibility/legal/support pages, install prompt, and localized marketing content.

## Instagramer Panel

Home dashboard, page/posts/stories, comments, direct messages, AI and flow tools, advertising, customer ads, market/bio-link, store, wallet, settings, search, upgrade, Google OAuth, password, sign out.

## User Panel

User home, business explorer, shop/product detail, customer shop, orders by status, cart checkout, wallet, settings, payment/ad status, messages, Instagramer login.

## Platform Capabilities

Authentication, authorization by partner role, localization, theme/direction management, notifications, PWA assets, API proxying, direct backend calls, file/media processing helpers, and custom rich text editor module.
