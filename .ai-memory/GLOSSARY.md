# Glossary

- Brancy: social commerce and Instagram business management application.
- Instagramer: managed Instagram account owner/operator.
- User panel: customer/buyer-facing area.
- Partner: delegated sub-admin account.
- PartnerRole: enum controlling partner access areas.
- PSG/package: package/pricing/feature entitlement domain.
- MyLink/Bio: public business link/profile surface.
- Proxy route: Next API route that forwards requests to backend services.
